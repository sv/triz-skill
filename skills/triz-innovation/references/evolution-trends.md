# S-curve stages and evolution lines

Trend analysis answers two questions before synthesis: which stage is this system on (a strategy
question) and which evolution line offers the next move (a tactical question).

## S-curve stages

| Stage | Detection signals | What it implies |
|---|---|---|
| Infancy | few users, rapid design churn, MPVs still contested, broad patents | investment decides survival; contradictions cluster around the main function |
| Growth | adoption accelerates, a dominant design appears, cost competition begins | resolve the contradictions limiting the decisive MPV |
| Maturity | incremental gains, margin pressure, commoditized MPVs | look for transition to the supersystem or a new MPV |
| Decline | a replacement system takes over the decisive MPV | harvest or jump; polishing the old system is wasted effort |

Stage discipline prevents two classic errors: applying growth-stage aggression to a
maturity-stage system, and polishing a declining system because its numbers still look fine.

## Evolution lines

| Line | Direction | Signals and examples |
|---|---|---|
| Dynamization | rigid → jointed → flexible → field | fixed rake → adjustable rake → leaf blower (air as the tool) |
| Transition to supersystem | mono → bi → poly → system with its supersystem | one blade → multi-blade; a bicycle → city bike-sharing |
| Increasing coordination | parts synchronize rhythm and parameters | matched impedances, synchronized strokes, tuned natural frequencies |
| Uneven development of subsystems | one subsystem lags and becomes the limiter | the weakest subsystem marks where the next contradiction is worth modeling |
| Transition to microlevel | mechanism shrinks toward particle and field interactions | mechanical relay → transistor → optical switch |
| Increasing controllability | fixed → adjustable → self-adjusting with feedback | passive suspension → active suspension |
| Decreasing human involvement | human does → machine does → system decides | manual → automated → autonomous |
| Increasing ideality | function preserved while parts and cost vanish | trimming and self-service: the function remains, the component disappears |
| Changing the working field | mechanical → thermal → chemical → electric → magnetic → electromagnetic | select the cheapest field that still delivers the function |

## Linking back to the workflow

The limiting parameter of the decisive MPV ([workflow.md](workflow.md), Main parameters of value)
plus the line that parameter sits on selects where the next contradiction is worth modeling.
Trends justify direction; they never substitute for substantiation — a trend argument is a
hypothesis until a test supports it.
